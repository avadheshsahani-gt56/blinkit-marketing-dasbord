# 🛒 Blinkit Marketing Analytics Dashboard

## 📖 Overview

This Power BI dashboard analyzes Blinkit's marketing performance across campaigns and channels. It provides insights into revenue generation, marketing spend, customer engagement, and conversion performance through interactive visualizations.

## 🎯 Business Objective

The objective of this dashboard is to evaluate marketing campaign effectiveness, identify high-performing channels, and support data-driven decision-making for marketing optimization.

## 📊 Key Metrics

- Revenue Generated: 15.52M
- Marketing Spend: 7.89M
- Clicks: 1M
- Conversions: 145K

## 📈 Dashboard Features

- Campaign Performance Analysis
- Revenue vs Spend Comparison
- Conversion Tracking
- Channel-wise Performance Analysis
- Monthly and Yearly Trend Analysis
- Interactive Filters and Slicers

## 🛠️ Tools Used

- Power BI
- DAX
- Data Modeling
- Data Visualization
